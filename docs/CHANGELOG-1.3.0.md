# 1.3.0 更新说明

新增十五项军需官任务，当前共 103 项任务、133 项采购（其中 24 项交换）、27 项新增藏身处配方。

## 新任务

- 留两包给司机：三种香烟的战局发现物搜集。
- 体面人的订单、空屋里的摆设：两段收藏品上交，提供医疗箱、武器箱等一次性成长奖励。
- 把路清出来、别敲锣、短家伙、轻装过街、他们还会开枪、封住北门：六段清路任务，逐步加入武器、地图、消音器、机械瞄具、服装、爆头、距离与持枪感染者条件。
- 往里面扔：累计十二次手投破片手雷击杀，不计闪光、烟雾和榴弹发射器。首次接取给两枚 RGD-5，其余自行获取。
- 借条五阶段：SKS → VPO-136 → AKS-74U → AK-74N → AKM，先完成作战目标，再交回枪。

全部使用新 ID，现有 88 项任务的目标、进度与标识保持；黑商的安全箱、收藏家和小本生意不变。新增用品会依据已有任务完成状态解锁，已完成前置无需重做。

## 借条规则

每阶段首次接取通过邮件提供一支完整枪及少量起步弹药，仅发一次。死亡、丢枪、重新登录、失败重接和后端重启均不补发。未完成作战目标不能提前交枪。

丢失后自行取得同型号枪和指定配件；允许替代实例，不要求战局发现。归还时需配件齐全、装配兼容、弹匣容量满足要求，当前耐久至少 50。交付前退弹，枪上的配件会一起收走。作战进度跨局保留，死亡不清零。

军需官增加必要的替换配件、30发弹匣和巴拉克拉法帽采购，以及 PBS-1、RGD-5、F-1、武器零件的材料交换。所有新增条目每次战局后限购一次，保留枪弹稀缺。

## 感知与界面

原生万圣节追击会持有玩家对象、持续读取实时位置，并把同图感染者纳入追击。此版本关闭这条全局追踪，限制为感染者自身的实际视野、近距离接触和有效声音。

只听到声音时，调查复制的声音位置；目视消失后保留短期已知位置，再结束搜索。邻近感染者可以听到局部报告，但报告只携带位置，不能继续层层转发玩家实时坐标。持枪感染者保留正常目视射击。新增路径在加载阶段同样生效，不增加AI、不进行每帧全图物品扫描。

包含1.2.5商人卡片修复，按战局补货的时间标记显示为“战局后补货”，不再挤出4096天倒计时。

## 安装

退出游玩目录的游戏、启动器及后端，运行项目根目录“安装到游玩目录.cmd”。安装与校验完成后，沿用 Server + Launcher 或“启动游玩.cmd”。本次未覆盖用户正在运行的玩家实例。
