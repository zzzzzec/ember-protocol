# 余烬协议 · Ember Protocol

适配 SPT 4.0.13 和 EFT 0.16.9.40087 的丧尸生存整合包。**2.21.6** 包含 295 项任务、652 条共用商品、190 项兑换和 71 个配方。六位原创商人与 Fence 随剧情开放，交易、藏身处和技能提供装备成长。

## 当前玩法

各地图每局生成有限的感染者名单。补刷按间隔逐只出现，出现前检查玩家距离和实体遮挡。感染者根据目视、近距离接触和有效声响聚集，尸体无法搜刮。

| 地图 | 整局总数 | 开场 | 同时上限 |
| --- | ---: | ---: | ---: |
| 中心区 | 30 | 12 | 12 |
| 海关 | 120 | 22 | 36 |
| 立交桥 | 90 | 20 | 20 |
| 工厂 | 56–140 | 20–30 | 20–30 |
| 储备站 | 140 | 24 | 24 |
| 实验室 | 180 | 24 | 24 |

工厂昼夜共用按空位逐只补刷的规则。物资丰度影响整局总量和同时上限，实际数量每局略有浮动。场上低于本局上限时短暂等待后开始补充，储备耗尽后停止。

物资丰度按地图单独成长，从 1.0 到 3.0。任务最多贡献 0.432，击杀每 100 只增加 0.05，最多贡献 1.568。进度在下一局掉落生成时生效，死亡结算也计入。丰度增加容器与散落物资数量，并提高现有物品池中较高价值物品的权重。

新版规则和开发服抽样见 [2.21.6 更新记录](docs/CHANGELOG-2.21.6.md)。

## 本地构建与安装

准备匹配版本的现有游戏安装、Python 3.8+ 和 .NET SDK 9.0.318。游戏程序集用作本机编译引用，第三方依赖按 `mods.lock.json` 从自己的安装或依赖归档提供。

```powershell
python tools/pack.py validate
python -m unittest discover -s tests -v
pwsh -File tools/Build.ps1 -GameRoot 'D:\Games\SPT-Player' -DotNet 'C:\Program Files\dotnet\dotnet.exe'
```

生成的整合包位于 `dist/ember-protocol-2.21.6.zip`。安装、隔离开发、验证和回退命令见 [安装说明](docs/INSTALL.zh-CN.md) 与 [开发工作流](docs/WORKFLOW.zh-CN.md)。

## 项目目录

| 目录 | 内容 |
|---|---|
| `src/` | 服务端、客户端与配套插件源码 |
| `content/` | 任务、交易、配方、文案及插图 |
| `config/` | 玩法参数和依赖配置 |
| `tools/`、`tests/` | 构建、安装、校验与测试 |

公开源码与游戏本体、第三方二进制、依赖归档、个人存档和本机诊断数据分开管理。`content/server/data/profiles.json` 存放用于创建角色的模板。
