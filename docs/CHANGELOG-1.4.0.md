# 1.4.0 · 夜车

在现有战役旁增加 16 项支线，总计 119 项任务、137 项采购、28 项交换、27 项配方。已有角色沿用当前进度，达到前置任务和等级后逐步开放。

- **维修台，4 项**：找工具、机械瞄具爆头、收集旧零件，最终替谢苗备齐一箱修理耗材。开放武器零件交换与高成本修枪工具交换；不直接赠送修理工具。
- **黑商杂事，3 项**：口袋里的打火机、烟茶，以及需要亲自跑两张图的收货单。材料上交均要求战局发现，钱与好感分段发放。
- **夜车，9 项**：修好卡车、清出海关道路、找回账本，再决定这一趟给妮娜运医疗物资，还是替黑商送货。共同段 3 项，两条分支各 3 项；同一角色只能完成其中一条。
- **四项交换**：维修零件、修枪工具、Salewa、7.62×39 HP 弹盒。每局各限一次，分别受任务及商人等级限制；夜车两项最终交换随路线开放。

选择任务的介绍和目标明确说明：**接取即选定路线**。另一项变为失败，另一条路线的后续不再显示。普通死亡不失败当前委托，已上交进度和路线选择保留，重启后仍生效。

文案围绕原有妮娜、科利亚与谢苗推进。目标包括物资上交、机械瞄具爆头、22:00—05:00 夜间清剿、持枪感染者及距离要求。详情见[任务与文案](design/night-truck.md)。

只允许军需官提供商人维修；修理工具走原版消耗与耐久损失。新增请求检查，缺工具、超量及重复工具编号均在扣除库存前拒绝。

新增启动错误日志。开发后端启动失败时给出日志位置并停止自己启动的失败进程；诊断包包含剧情状态、内容规则和经济报告。游玩启动仍使用原生服务器、启动器窗口。

本版保留 1.3.2 的地图数量、感知、普通物资刷新和估值策略。原有 103 项任务、五段借枪和既有商品保持原进度与标识。后端测试记录见[验证记录](VALIDATION.md)，实际夜战、击杀条件和长期收支仍以游玩表现为准。
