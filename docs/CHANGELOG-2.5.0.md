# 2.5.0 · 留给下个人

原有三十个主线位置的中文正文、接取回信与完成回信现已逐章改写。后五项衔接外部联系和后续安排的准备，保留人物间尚未化解的分歧，没有假称完整命运结局已经上线。

烟瘾、两段收藏订单、六段清路、掷弹兵和五段借枪改为独立文案，中文精修累计 68 项任务。减少反复用库房小插曲和冷笑话结尾，部分回信直接留在具体事情或未回答的问题上。

借枪目标栏明确地图、机械瞄具或指定光学配置、归还部件和撤离判定，保留现有跨局进度、首次发放和同型号替代规则。所有旧任务条件与奖励、商店、交换、配方和地图阶段数值不变。

修正一个诊断误报：借枪提前结算被另一道校验拒绝时，不再记录为已完成。实际状态达到成功后才写完成事件，重复请求继续保持奖励和进度不变。
