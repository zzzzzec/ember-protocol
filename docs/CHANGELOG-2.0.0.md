# 余烬协议 2.0.0

本版在 `feature/threat-generator-economy-v2` 开发，建议以独立新角色开始；旧账号、任务 ID 和存档继续保留。

## 战斗

- 十种基础感染者类型：普通、活跃、快速、工人、警卫、突击、重装，以及三种持枪组合。
- 每局先用随机种子生成固定名单。评分考虑血量、速度、视听、反应、枪械和装备磨损，并限制单体强度、各类型比例、普通感染者下限与装备渲染预算。
- 地图常态总数仍是 30 / 60 / 90 / 110 / 140 / 180，持枪总数 1 / 4 / 7 / 10 / 15 / 22，同时存活加待生成上限仍为 12 / 16 / 20 / 24 / 24 / 24。
- 基础头部血量 35～40，胸部 95～150；不再靠地图等级统一叠高血量。
- 丧尸插板剩余耐久约 15～70%，分布偏低：65% 在约 15～35%，30% 在约 35～50%，5% 在约 50～70%。修复上限为模板最大值的约 55～90%。内衬和头盔也有磨损。
- 感染者简化骨架的插板与头部命中映射补齐，仍由原生系统计算穿透、跳弹、钝伤和耐久；开放式头盔保留眼睛与下颌弱点。该映射近似简化碰撞表面，不等同于普通角色完整插板几何。
- 听视敏感度无法绕过有效信息条件；继续禁止全图共享玩家实时位置。
- 战斗装备与尸体掉落仍分别控制，未开放整套护甲的稳定掉落。

## 经济与新档

- 弹药、医疗、普通物资和贵重品恢复原版手册估值；现金商品优先采用原版商人的现金售价，无现金来源时采用原版手册价加基础商店加价。
- 枪械与配件单独平衡。PM 6,500、TOZ 9,000、SKS 28,000、AKS-74U 43,000 卢布；保留相关后续武器任务解锁。
- PM 与 TOZ 无需先完成任务。基础 PM 弹 14 卢布，每局基础限购 96 发；低级步枪弹和鹿弹较早可得。中后期增加七种限量穿甲弹。
- 地图枪械、弹药、医疗的出现量再降低，普通材料来源不作额外削减。现金不再是早期弹药的主要门槛。
- 低价值普通弹生产改为专用复装弹或中穿弹批次，相关弹药交换、剧情说明及参考价同步更新。
- 原版拆弹制作火药的批量上限改为一份，避免低价弹形成现金购入、制作、回收的获利路线。
- 新档仍为 18,000 卢布、440 生命上限、48 发弹药；两个备用 PM 弹匣预装八发，余弹与 AI-2 放入口袋。增加一个止血带和一个夹板，不写入既有角色。
- AI-2 每次部署结算限购三个，绷带六个、止血带六个、夹板三个；继续保留部分恢复的资源取舍。

## 验收边界

规则矩阵、原生生成、购买、限额、剧情交换与维修分别验收。开发场景的免伤角色、合成命中和批量 NPC 死亡只用于机制验证，不代表正常生存难度或长期经济已经平衡。帧率按实际地图与视角记录，不能由生成器规则检查推断。

## 本机管理

新增 Admin.ps1：检索账号、物品、任务，排队发放原生非 FIR 邮件，或将已接受任务改为可提交/成功。下次 Server 启动执行，逐条备份、审计并防止重放；直接标记成功不隐式补发任务奖励。
