# 2.2.0：通讯接通与开局节奏

## 可玩内容

- 初始可接任务由九项减为两项：主线与基础手枪。补给、短枪、长枪、精度和机械瞄具入口按前六项主线分批出现；原有任务、条件、商品 ID 保留。
- 克莱尔在第七项主线后接通；八、九项主线由她直接委托，另有三项可选的串联支线。前十五项主线衔接《回执》作者设定，未接入后段命运选择或追溯解释旧夜车承诺。
- 克莱尔使用既定 Style A 头像；只接手原有八项商品，原售价、限购和商品前置不变，原窗口不保留副本。收购电子、电池、光学、照明与耳机，维修仍归凛。
- 新支线合计 4,300 经验、32,000 卢布、0.14 克莱尔好感，无枪械、弹药或药品赠礼。全部是可选内容，不作为主线或恢复补给的门票。
- 克莱尔好感门槛为 0 / 0.06 / 0.14 / 0.22，人物等级仍为 1 / 8 / 18 / 30；当前两项主线与三项支线合计可到 0.22。构建检查会拒绝无法靠现有任务达到的联系人末级门槛。
- 前十五项主线、三项克莱尔委托、六项医护委托和五项基础武器委托，共二十九项的中文正文、接取回信、完成回信分别重写；补足日常、分歧和熟悉过程，移除仍沿用旧剧情的接取信。全剧情真相仍只在作者资料中，不直接塞入任务解释。
- 合作撤离保留原生撤离和返场补货，关闭 Fence 额外礼包及合作撤离声望；历史已领取奖励保留，未领取的精确匹配赠礼归档，原创任务奖励保留。
- 找到的弹药包按包装标称数量填满，弹药包出现率及散装子弹限量不变；不对仓库物品、旧邮件或已持有弹药包自动补弹。五项原有低级弹药交换改用与实际内容相符的包装。
- 弹药零售按口径、肉伤和穿透重算，同步手册、回收与 Fence 参考值。一级全部弹药买满约从 10,054 升至 43,390 卢布；基础 PM 弹 90/发，三匣 24 发为 2,160 卢布，开荒仍可选择只补自卫所需。限购、枪价和普通材料价格不变。
- 两项原有 Ultra Nosler 配方改为 32 发/3 小时和 40 发/2 小时，分别保留原有主线与工作台三级要求；消耗一份绿火药及一或两份金属零件，工具不消耗。25 发普通鹿弹交换改收一份金属零件。其余原有弹药制作数量及任务门槛不变。

## 旧档规则

已接与待完成任务仍可继续；不取消任务、不清除计数、不撤销旧奖励。已完成主线自动识别接触条件。首次增加联系人时，仅将其应得的既有任务好感投影一次；不补发物品或现金。转移商品的旧个人购买记录同步带入新窗口，返场仍使用同一个原有补货事务。

接触状态按档保存。unknown 可以由前置推进为 open；departed/dead/suspended 不能被登录投影复活。本版没有新增自动离队或死亡触发，只为后续明确剧情事件保留状态边界。

## 验收

`native_contacts_check.py` 在独立 Development 档检查新档两项可接、直接接取锁定任务与未接通交易的拒绝、两名联系人分期解锁、原生购买、商品无副本，以及模拟旧档的任务/计数/库存/邮件/购买额度保留。经过两次受控后端重启复核幂等。

全任务检查按依赖顺序运行，保留原有互斥分支、借枪归还、奖励、交换和配方验收。原生接口使用合成进度，不等于实战计数或新商人 UI 验收；不因本次叙事修改重述 60 FPS 或全地图结论。玩家正在运行的实例不被停止或自动覆盖。

本机记录：146 项可达任务完成，3 项互斥分支跳过；34 项部署/工作区/管理测试通过；三项克莱尔委托的上交、错误/非战局物品拒绝、接取邮件、计数保留与单次奖励通过。原有 146 项任务的完成条件、失败条件和 Started 奖励逐项比较保持原样。

补充验收：全任务检查逐项比对实际奖励邮件中的物品模板与数量下限，包含三项新委托的现金附件；构建校验拒绝奖励 target 不在 items 内的引用。实机发现过的三项新现金奖励引用错误已在首次 Player 发布前修正，复测正常显示 8,000 卢布。没有向真实角色补发测试物品。

独立客户端核对：旧档缓存过未接任务时，勾选“显示未解锁”仍只显示两项开局任务；长文完整显示，接取后独立回信正常；凛、妮娜与克莱尔头像、两名联系人四级好感、6/8 项转移商品及新支线目标可见。任务进度来自合成 QA 档，未据此宣称完成了实战战役。
