# 2.7.0 · 回信之前

第九项主线之后新增一段家属回信支线，共四项原生任务、两条互斥路线。两份草稿都能先接受、阅读；点击其中一份的“完成”才确认发送，另一稿收回。发送内容与收件范围写在正文里，操作说明置于首屏。后续回信随选择变化，不新增开局任务，也不要求为了读信额外搜集物品或等待现实时间。

发送按角色分别保存收件人、范围、内容原文与散列。接受、普通死亡、退出和重启不会替玩家作决定；重复完成不重发奖励。旧夜车仍在接受时承诺，不把新规则追溯到旧档。

补上客户端原生互斥条件，让另一稿在确认发送后同步关闭；重复失败回调不再重复寄信，也不能把已完成任务改成失败。并发测试发现原生物品事件响应字典的竞争，现将保护覆盖到整个异步请求的响应创建与清理结束。

任务共162项，中文精修109项，现有六张场景图覆盖91项任务。既有158项任务的字段、目标、奖励与发布人全部保留；商店、交换、制作、借枪和感染者配置不变。完整去留、人物命运和新版结局继续分段接入。
