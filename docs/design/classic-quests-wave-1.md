# 第一批经典任务改编方案

状态：已实现于 1.3.0 安装包，新增 15 项任务，合计 103 项，全部由军需官发布。既有安全箱、收藏家与小本生意继续归黑商。本文保留设计依据和实际采用的文案；战局目标尚未逐项实战验收。

最后确认：试驾每阶段只发一次枪。枪丢失后不补发，玩家自行取得同型号枪和要求的配件交回；击杀进度保留，允许用替代实例归还。没有押金、付费补领或死亡后重发。

## 节奏与奖励

烟瘾提供前期搜集目标，两段奢侈人生消耗贵重物，六段清路任务让玩家逐步接触消音、距离、爆头和持枪感染者。掷弹兵单独考察手雷；试驾沿现有步枪采购链逐级开放。

以下经验、金钱、好感和数量已作为首版平衡值写入。除写明存活撤离的条件外，击杀可以跨战局累积，死亡不清空。物品交付不要求在同一局收齐。近战感染者与持枪感染者分别明确标注，不能把原版 PMC 条件直接留下。

所有任务使用新的自有 ID，参考原版任务结构，重新写文案和奖励。不上交 PMC 狗牌，不要求未开放地图或原版剧情专用物品，不另发安全箱。不同支线允许共享符合条件的击杀，不叠加巨额现金和弹药奖励。

## 借条（参考试驾，五阶段）

### 已确认规则

- 每阶段仅首次接取发放一支完整枪、指定配件及表内起步弹药，通过任务邮件领取。没有补领、押金或按死亡重发。
- 必须先做完上一阶段，再具备对应枪械现有采购解锁。首段另需完成“给车让路”；后续地图难度随现有主线推进。
- 击杀按同型号和指定配置计数，不绑定最初发放的物品实例。丢枪不丢击杀进度；自己找来的合格枪也能继续打。
- 达成击杀后归还一支同型号、可使用且装有指定配件的枪。替代枪不要求战局发现，不要求原序列号。
- 首版归还最低当前耐久 50；不要求恢复满耐久。缺失必要零件、错误型号或缺少指定附件不能交付。起步弹药属于消耗，不需归还。
- 只按表列指定附件验收；其他必要零件要求兼容可用，允许等效替代。交枪前退弹，避免把自己的弹药一起上交。
- 军需官要能出售或交换所有硬性指定的替换配件，按战局限量。枪的替代来源沿现有现金与交换采购，不另外设补领按钮。
- 不要求全部借条完成才可继续主线；玩家可以先搁置、搜集替换件。不能通过放弃、重接、重登或重复请求再次领取首发武器。

## 实现顺序与检查

十五项任务均已落地，独立后端完成接取、奖励和五段借条的归还流程；等待用户关闭游戏后统一安装。下列检查同时作为后续维护要求。

1. 对照当前任务、物品价格和配方，核对收藏品竞争、材料交换与新奖励回收价值。医疗供应仍以部分恢复为前提。
2. 借条使用原生任务开始奖励与 `WeaponAssembly` 归还条件。当前原生枪匠任务已存在型号、必要附件和耐久条件，但必须在专用角色上验证客户端是否正确显示和消费整枪及附件。
